# 자료 출처와 범위

`grammar.json`은 국립국어원 [한국어기초사전](https://krdict.korean.go.kr/)의 항목을 참고해 직접 쓴 기초 문법 요약 24개입니다. 사전 전체나 학습자 말뭉치를 내려받은 파일이 아닙니다. 각 자료에는 참고한 사전 항목 또는 검색 링크가 있습니다.

사전 자료는 별도 표시가 없다면 [CC BY-SA 2.0 KR](https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo) 조건으로 제공됩니다. 사전 내용을 인용하거나 각색해 게시할 때에는 출처 표시와 동일조건변경허락 조건을 확인하세요. 멀티미디어 자료는 사용하지 않았습니다.

`evaluation_cases.json`의 문장 8개는 이 프로젝트를 위해 직접 쓴 평가 예시입니다. 앱이 받을 수 있는 문장 목록이 아니며, 모델 평가를 마친 결과도 아닙니다.

[국립국어원 한국어 학습자 말뭉치](https://kcorpus.korean.go.kr/)는 오류 주석 자료로 검토했지만 이용 신청이 필요해 이 저장소에는 넣지 않았습니다.
