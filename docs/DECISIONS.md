## 2026-11-11 · v2 재작성 (Claude)

사용자 지시: 처음 기획(7장)을 확인하고 포트폴리오용으로 다시 만들 것. 근거는 `docs/AUDIT-2026-11-11.md`.

- **v1은 `v1-blog` 태그로 보존한다.** 발행된 8·9·11장이 v1의 함수명, 기준 숫자, 단계명을 그대로 인용하므로 글의 코드 링크는 이 태그를 가리키게 한다. 태그는 로컬에만 있다(푸시 전).
- **범주를 9개에서 7개로 바꾼다**: 조사, 어미, 시제, 높임·말투, 문형, 어휘, 맞춤법. v1의 9개 중 4개는 문법 자료가 없어 근거도 기록도 남지 않았다. 화용·자연스러움은 범주가 아니라 '덜 자연스러움' 판단으로 다루고, 학습자에게 흔한 맞춤법을 범주로 추가했다.
- **문법 자료를 새로 쓴다(59건)**: 항목마다 규칙, 올바른 예문, 오류 사례(틀린 문장 → 고친 문장 → 이유), 구분 기준. 7장이 검색 대상으로 든 문법 설명·용례·학습자 오류 사례를 한 항목에 담기 위해서다. 사전 문장을 옮기지 않았고 링크는 사전 검색 결과로 건다(항목 번호를 확인할 수 없어 지어내지 않기 위해). 검수는 사용자 몫으로 남긴다.
- **`-었어서`는 '덜 자연스러움'으로 고정한다.** 자료에는 규범상 결합 제약과 구어 사용 증가를 함께 적는다.
- **검색은 범주로 거르지 않고 전체에서 찾되 기준 점수를 둔다.** 모델이 범주를 잘못 붙여도 맞는 자료를 찾고, 무관한 자료가 근거로 붙지 않게 하기 위해서다. 기준은 2026-11-12 실제 평가로 0.75로 보정했다(아래 항목).
- **모델이 형식을 조금 어겨도 요청을 실패시키지 않는다.** 잘못된 후보·인용은 버리고 이유를 기록하며, 형식 검사 실패는 1번 재시도한다. v1은 공백 하나 차이로도 502였다.
- **도구 호출은 네이티브 function calling이 아니라 구조화 출력의 `tool_calls`로 받는다.** 점검 보고서에서는 네이티브 호출을 권했으나 바꿨다. 저장 결과가 피드백 생성에 필요하지 않아 왕복하면 모델 호출만 한 번 늘고, 이 환경에서 실제 API로 시험할 수 없어 검증 못 한 호출 방식을 넣지 않기로 했다. 대신 제안이 `grammar_id`와 이유를 싣도록 해 "제안 → 검증 → 실행" 경계에 실제 판단이 담기게 했다. 7장 7.14(도구 결과를 다시 Context에 전달)와 다른 점이며, 원하면 이후 네이티브 호출로 바꿀 수 있다.
- **데모 시드 기록을 없앤다.** 새 사용자가 첫 문장에서 "반복된 실수"라는 말을 듣는 문제를 없애기 위해서다. 반복 횟수는 모델이 아니라 코드가 DB에서 센다.
- **'고친 문장'과 반복 횟수는 코드가 만든다.** 모델에게 맡기면 원문의 다른 부분까지 바뀔 수 있다.
- **연습문제 정답은 서버에만 두고 풀이 결과를 저장한다.** 학습 루프(틀림 → 연습 → 기록)를 닫기 위해서다.
- **수준과 모국어는 사용자가 정한다.** 기본 수준은 B1, 모국어는 비어 있다. v1은 전원 "B1·영어"로 표시했다.
- **요청 제한은 학습자별로 두고 실패한 요청은 한도에서 뺀다.**
- **화면은 2026-11-11 시안(검정·흰색·코발트, 워드마크 로고)대로 구현한다.** 분석 과정은 단계가 끝날 때마다 서버가 한 줄씩 보내 실시간으로 표시한다.
- **DB 테이블 이름을 바꾼다**(`learner`, `attempt`, `correction`, `practice`). v1 테이블과 같은 파일에 있어도 충돌하지 않는다. v1 기록은 옮기지 않는다.

## 2026-11-12 · 실제 모델 검증 (Claude Code)

- **`EVIDENCE_MIN_SCORE`를 0.75로 정한다.** `evaluate.py --min-score 0`으로 46문장을 실제 실행해 보니 기대한 자료의 최고 점수는 0.762~0.887, 함께 붙는 무관한 두 번째 근거는 0.728~0.811이었다. 0.75는 맞는 근거를 모두 남기고 0.73대 잡음을 거른다. 정답 최저점과의 여유가 0.012뿐이라 자료를 바꾸면 다시 보정한다.
- **임베딩 호출은 429에 30~60초 간격으로 최대 3번 시도한다.** 무료 등급 한도가 분당 100텍스트인데 문서 청크가 146개라 첫 계산이 항상 실패했다.
- **문서 임베딩 캐시(`data/.cache/`)를 저장소에 넣는다.** 배포 서버가 시작할 때마다 146건을 다시 임베딩하지 않게 하기 위해서다. 파일 이름에 자료 내용 해시가 들어 있어 `grammar.json`을 고치면 자동으로 다시 계산한다.
