## 알려진 문제

- **GitHub 푸시로 자동 배포되지 않는다.** 서비스는 저장소에 연결돼 있지만 푸시 후 새 배포가 생기지 않았다. 지금은 `railway up --service web`으로 올린다. Railway GitHub 앱 권한을 확인해야 한다.
- **연습문제 검증은 조사 형태만 한다.** "어제 영화( ) 봤어요"에 '을'을 정답으로 낸 사례 뒤 `fix_particle_answer()`를 넣어 을/를·이/가·은/는·과/와·으로/로를 빈칸 앞 받침에 맞춘다. 해설 문장은 고치지 않으므로 고친 경우 해설과 어긋날 수 있다. 어미·어휘 문제의 정답 타당성은 여전히 검증하지 않는다.
- **모델 설명의 사실 오류는 검증하지 않는다.** 배포본에서 '영화이 봤어요'에 대해 "받침이 있는 명사 '영화'"라고 설명했고(교정 자체는 '영화를'로 맞음), 을/를 문제에 '에: 시간' 자료가 붙었고, 이 실수는 학습 기록에 남지 않았다. 받침 형태 오류 사례를 자료에 넣은 뒤 평가에서는 '영화를'과 p-object를 찾았지만, 보정 실행에서는 모델이 '영화가'로 잘못 고친 적도 있다(교정 자체가 모델 몫이라 자료로 다 막을 수 없다).
- 볼륨 없음: 학습 기록이 재배포 때 초기화된다. Free 플랜 월 $1로 상시 실행이 버티는지 미확인.
- 실제 휴대폰에서는 보지 않았다(브라우저 375px 에뮬레이션만).
