## P1 — 설계

**RAG·문법 자료**
- 검색이 모델이 붙인 범주로 하드 필터된다(`rag.py:88`). 모델이 `책이→책을`을 `grammar`로 분류하면 안/못/-아야 하다만 후보가 된다. 최소 유사도 기준이 없어 항상 2건이 "근거"로 붙고, 저장 검증("인용 근거 있음")도 그대로 통과한다. → 전체 검색 + 범주 가산점, 점수 하한, 근거 없음 상태 허용.
- 검색 질문이 모델 자신의 분석(범주·제안·설명)으로 만들어져, 근거가 판단을 독립적으로 견제하지 못한다(`pipeline.py:89-91`). 원문 표현 기반 질의를 병행.
- 자료 24건의 내용이 규칙보다 유보문("문맥을 확인한다", "무조건 바꾸지 않는다") 위주이고 올바른 예 1개뿐이다. 오류 대조 예(`*책이 읽었어요 → 책을`), 구분 기준, 흔한 학습자 오류가 없다. 근거로 인용해도 교정을 뒷받침하지 못한다. → 항목 스키마를 `rule / correct_examples / error_examples / contrast / level`로 재설계.
- `-었어서`: 자료와 프롬프트가 "일률 금지 안 함"만 말하고 규범 문법의 기본 규칙(-아서/-어서는 -았/었-과 결합 제약)을 적지 않았다. 구어 확산 연구가 있어 입장 자체는 방어 가능하지만, 학습자용이면 "규범상 제약 + 구어 사용 증가"를 둘 다 명시하고 판단은 `less_natural`로 고정하는 결정이 필요하다. → DECISIONS에 기록할 항목.
- 청킹은 명목상이다(24건 중 8건만 2문단, 총 32청크). `level` 필드는 로드만 하고 쓰지 않는다. `source_urls` 24건 중 10건은 항목이 아닌 검색 결과 URL이다. 나머지 ParaWordNo 링크의 실제 일치 여부는 미확인.
- 문서 임베딩을 서버 시작마다 다시 계산하고, 오류 후보마다 질의 임베딩을 순차 호출한다. 사전 계산 파일 + 질의 일괄 처리.

**Tool Calling·학습 루프**
- `profile_updates`는 분석 결과와 세 필드가 완전히 같아야 통과하고 저장값도 분석값을 쓴다(`learner.py:143-145,173`). 제안이 실어 나르는 정보가 "i번 저장" 한 비트뿐이라 Tool Calling 시연으로 약하다. 6·7장이 가르친 `update_learner_profile` 스키마·함수 호출과 간극이 있다. → Gemini function calling으로 `get_learner_profile`/`update_learner_profile`을 실제 선언하고 "제안→검증→실행" 경계는 유지.
- 임계값이 세 곳에 흩어져 있다: 0.65(`pipeline.py:65`), 0.75(`learner.py:146`), 0.75(프롬프트 `llm.py:152`). 설정 한 곳으로.
- 연습문제: 선택지 중복·정답과 제안의 일치·`target_category` 유효값 검증이 없다(자유 문자열). 풀이 결과는 저장되지 않아 "틀림→연습→기록" 루프가 닫히지 않는다. 기록에는 원문 문장·판단도 남지 않는다.

**코드 구조**
- `src/llm.py`가 스키마 + 클라이언트 + 프롬프트 + 조립(`build_model_resources`)을 다 갖고 `rag`를 import한다. `learner.py`는 스키마 때문에 `llm`을 import한다. → `schemas.py` 분리, 조립은 `app.py`/factory로. 단 9장 글이 현 구조를 설명하므로 아래 "블로그" 절 순서를 따른다.
- `GeminiClient.parse`: system 지시와 데이터가 한 문자열, temperature 미지정(평가 재현 불가), timeout·재시도·토큰 사용량 기록 없음.
- `app.py`: 요청 제한이 전역 1개라 한 사람이 모두의 한도를 소진하고 실패 요청도 차감된다. `GET /api/profile`이 학습자 생성·시드 삽입을 한다(부작용 있는 GET, 무제한 ID 생성). `except Exception`이 DB 오류도 "모델 연결 실패"로 표시. 502 본문에 내부 예외 메시지가 그대로 나간다.
- 평가: 8문장, 결과 파일은 gitignore라 저장소에 품질 근거가 없다. 포트폴리오용으로 50문장 이상 + 탐지 정밀도/재현율, 검색 hit@k, 오탐률 표를 README에 싣는다.
