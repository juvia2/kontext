# 프로젝트 개요

Kontext는 「LLM.zip | 압축 해제」 시리즈의 실습 저장소이자 포트폴리오용 개인화 한국어 학습 LLM 데모다. 사용자가 한국어 문장을 입력하면 문장 분석, 문법 근거 검색, 피드백, 연습문제 생성, 학습 기록 갱신을 실행하고, 그 과정을 단계별로 화면에 보여 준다.

## 버전

- `v1-blog` 태그: 시리즈 8~12장이 설명하는 코드.
- `main`: 2026-11-11에 점검 후 다시 만든 v2. 시리즈 3부의 소재.

## 실제 작업 파일

- `README.md`: 소개, 단계, 기준, 실행, 평가, 배포.
- `CODE_GUIDE.md`: 코드 구조와 블로그 챕터 연결.
- `app.py`, `src/`, `data/`, `web/`, `evaluate.py`, `tests/`: 앱, 파이프라인, 자료, 화면, 평가.
- `docs/DECISIONS.md`, `docs/HANDOFF.md`, `docs/AUDIT-2026-11-11.md`: 결정, 인계, 점검.

## 작업 규칙

독자가 코드로 시스템의 연결 구조를 이해할 수 있도록 파일별 역할과 실행 흐름을 명확히 한다. 판단 기준 숫자는 `src/config.py`에만 둔다. `.env`와 키는 문서나 Claude 프로젝트 컨텍스트에 복사하지 않는다. Git 원격은 `juvia2/kontext`다. 공개 배포 여부는 로컬 실행 주소만으로 판단하지 않는다.
